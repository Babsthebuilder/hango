# Product

HANGO reveals and verifies the hidden relational geometry behind decisive football moments. It is intended to help an audience see support triangles, passing lanes, off-ball relationships, and alternative decisions, then understand which parts of a story are observed, calculated, estimated, or interpreted.

## Phase 0/1 outcome

This phase establishes a deterministic, offline-first foundation:

- versioned mathematical definitions;
- strict football-state contracts;
- deterministic synthetic fixtures;
- tested geometry, passing-lane, and interaction primitives;
- a minimal API and web shell;
- evidence and publication rules ready for later product work.

## Explicitly deferred

Production opportunity/xT models, the Triangle Engine, Ghost Pass UI, video ingestion, heatmaps, Foundry agents, Azure deployment, managed identity, studio rendering, localization, Match DNA, and 3D replay are not part of this phase.
