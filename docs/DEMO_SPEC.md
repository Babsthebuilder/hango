# Demo Specification

The later judge journey is:

1. start from a decisive goal;
2. reveal the observed geometry;
3. inspect a support triangle;
4. compare the actual decision with a clearly marked Ghost Pass hypothesis;
5. inspect evidence and verification status;
6. generate a concise studio-ready explanation.

Phase 1 implements only a boot screen and the trustworthy mathematical/data foundation. It does not simulate this journey yet.
